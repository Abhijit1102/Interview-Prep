# 📚 Queue Data Structure (C++)

A simple implementation of the **Queue** data structure in C++ demonstrating FIFO (First In, First Out) behavior.

---

## 🚀 What is a Queue?

A **Queue** is a linear data structure that follows:

> **FIFO Principle** – First In, First Out

The element inserted first will be removed first.

### 📌 Real-Life Examples

- Ticket booking lines
- CPU task scheduling
- Printer queue
- Call center support systems

---

## 🛠 Features

- Enqueue (Insert element)
- Dequeue (Remove element)
- Peek / Front element
- Check if queue is empty
- Display queue elements
